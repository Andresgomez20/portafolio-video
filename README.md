# Portafolio de video — Jorge Andrés Gómez

Edición de video y diseño para marcas pequeñas: reels, anuncios, intros con logo y piezas para redes.

**Ver en línea:** https://andresgomez20.github.io/portafolio-video/

Sitio estático (HTML, CSS y JS, sin dependencias). Los trabajos se editan en `datos.js`; los videos e imágenes van en `media/`.
Las piezas marcadas como *Pieza de muestra* usan marcas ficticias.
